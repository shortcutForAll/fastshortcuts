Comet Browser Keyboard Shortcuts

Every Perplexity Comet shortcut that matters: Alt+A (Opt+A on Mac) opens the Assistant sidebar, Alt+S summarizes any page, Alt+Shift+V starts Voice Mode, and Shift+Enter searches Google instead of Perplexity. Plus the / slash-command Shortcuts system, the Opt+Tab recent-tab switcher, and the full Chromium key set — sourced from Perplexity's official quick start guide and Comet Help Center. Also using the Perplexity web app? See our Perplexity shortcuts.

Why Comet Shortcuts Matter (August 2026)

Comet is now the most-used AI browser — and after OpenAI discontinued ChatGPT Atlas on August 9, 2026, it's the clear default for AI-first browsing. The whole point of an AI browser disappears if every action needs mouse travel, so Comet puts its three core actions on dedicated keys: Alt+A for the Assistant, Alt+S for one-tap page summaries, and Alt+Shift+V for hands-free Voice Mode. Its signature feature is even called Shortcuts: type / in the Assistant to run saved prompt automations like /summarize or /dailybrief that execute multi-step tasks — no code, no extensions.

Because Comet is Chromium-based, everything you know from Chrome carries over: tabs, bookmarks, DevTools, and zoom all use the same keys. The one deliberate difference is the address bar — Enter asks Perplexity, Shift+Enter searches Google — and the Mac-only Opt+Tab recent-tab switcher (Windows users can enable it at comet://settings/shortcuts). Everything below is labeled by where it comes from, so you know which keys are Comet-specific and which are standard browser behavior.

Comet Shortcuts — Frequently Asked Questions

Does the Comet browser have keyboard shortcuts?

Yes. Comet ships AI-specific shortcuts on top of the standard Chromium set: Alt+A (Opt+A on Mac) opens the Assistant sidebar, Alt+S (Opt+S) summarizes the current page, and Alt+Shift+V (Opt+Shift+V) starts Voice Mode. You can view and remap browser shortcuts at comet://settings/shortcuts.

What is the Comet Assistant shortcut?

Press Alt+A on Windows or Opt+A on Mac to open or close the Comet Assistant sidebar on any page. The Assistant can answer questions about the page you're viewing, compare information across tabs, fill forms, and automate multi-step tasks.

How do I summarize a page in Comet with the keyboard?

Press Alt+S on Windows or Opt+S on Mac. Comet opens the Assistant and asks Perplexity to summarize the current web page — it works on articles, videos, PDFs, and social media threads.

What are Comet Shortcuts (slash commands)?

Comet Shortcuts are saved prompt automations you trigger by typing / in the Assistant followed by a name, such as /summarize or /dailybrief. Type / alone to open the Shortcuts menu, browse saved automations, or create new ones — no coding required. They can run multi-step actions like extracting data, drafting replies, or filling forms.

How do I switch between recent tabs in Comet?

On Mac, tap Opt+Tab to swap between your two most recent tabs, or hold Opt and keep tapping Tab to cycle through a visual menu. On Windows, the same behavior uses Ctrl+Tab but must first be enabled at comet://settings/shortcuts, because Ctrl+Tab cycles next-tab by default.

How do I search Google instead of Perplexity in Comet?

Type your query in the address bar and press Shift+Enter instead of Enter. Enter sends the query to Perplexity's AI answer engine; Shift+Enter runs a classic Google search — useful when you want links rather than an AI answer.

Is ChatGPT Atlas discontinued and what replaces its shortcuts?

Yes — OpenAI shut down the Atlas browser on August 9, 2026 and moved its agentic features into the ChatGPT desktop app. If you're switching from Atlas to Comet, the closest equivalents are: Atlas's Cmd+Shift+A sidebar becomes Alt+A / Opt+A in Comet, and tab management keys are nearly identical since both browsers are Chromium-based.

Can I customize Comet keyboard shortcuts?

Yes. Open comet://settings/shortcuts to view and configure Comet's browser shortcuts, including enabling Cycle Most Recent Tabs on Windows. Slash-command Shortcuts are fully custom — you name them yourself when you create them in the Assistant's / menu.
