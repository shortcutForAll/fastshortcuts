Zen Browser Keyboard Shortcuts

A searchable cheat sheet of Zen Browser keyboard shortcuts for Windows, macOS, and Linux — Compact Mode, Workspaces, Split View, Glance, copy URL as Markdown, and the Firefox keys Zen inherits. Includes how to remap bindings in about:preferences#zen-shortcuts and why Ctrl+Alt defaults fail on AltGr layouts. Pair with Chrome shortcuts and Comet shortcuts.

Verified against Zen's official shortcut reference · Last checked 10 September 2026

What's in this Zen Browser cheat sheet

Zen is a Firefox fork with vertical tabs, Workspaces, Split View, Compact Mode, and Glance previews. The shortcuts people actually search for are the Zen-only chords — not Ctrl+T. This page lists every editable binding from Zen's official keyboard shortcuts docs, grouped the way you use them, with Windows/Linux and macOS tabs and a search box.

Last verified 10 September 2026. Windows and Linux share the published table. macOS is not a blind Ctrl→⌘ swap: tab cycling stays Ctrl+Tab (⌘+Tab switches apps), history is ⇧+⌘+H because ⌘+H hides the window, and tab 1–8 uses ⌘+1–8. Firefox keys that never appear in Zen's settings page still follow Mozilla's Firefox list.

The one thing to know first

Almost every Zen-specific default is Ctrl+Alt plus a letter. That combo is also AltGr on a large share of Windows keyboards. If Compact Mode, Workspaces, or Split View do nothing, remap them — do not assume the app is broken. Workspace 1–10 and Reset pinned tab have no default; bind them yourself if you use Spaces.

How to customize Zen Browser keyboard shortcuts

Open Settings → Keyboard Shortcuts, or paste about:preferences#zen-shortcuts in the address bar. If the list is empty, set zen.keyboard.shortcuts.enabled to true in about:config.

  1. Click the text field next to an action.
  2. Press the new combination, then press Esc to save.
  3. Green outline = saved. Red outline + “Conflict with another shortcut” = taken. Press Backspace to clear the field, or clear a shortcut you do not use and reuse that combo.

Not every Firefox shortcut appears here. If a Firefox-derived key is missing from the settings page, you cannot use it as a custom shortcut yet — report it on the Zen GitHub issues page. Some remaps look free in the UI but still fire the original Firefox action; if that happens, pick a different combo.

Why Ctrl+Alt shortcuts fail on Windows (AltGr)

Compact Mode, Workspaces, Split View, Reader Mode, and the AI chatbot sidebar all default to Ctrl+Alt. On Windows, Ctrl+Alt is the same as AltGr on layouts used by a large share of the world (German, Polish, UK, US-International, and others). Windows types a character — for example © on US-International with Ctrl+Alt+E — and Zen never sees the shortcut. This is documented in zen-browser/desktop#9127. The fix is to remap those actions to keys that do not include Ctrl+Alt.

Glance, Essentials, and Compact Mode details

Glance is not in the official key table. Preview a link with Alt+click (Option+click on Mac); Escape closes it. Alt+1–8 (⌘+1–8 on Mac) count Essentials and pinned tabs in the index, so “tab 1” is often an Essential, not the first regular tab. Ctrl+Tab wraps from the last tab back through Essentials, then pinned, then regular tabs. Enable “Ctrl + Tab cycles through tabs in recently used order” under Settings → General → Tabs if you want the MRU popup (up to seven tabs).

Split View toggles apply when you have multiple sidebar tabs selected. They do not retile an already-split group — unsplit with Ctrl+Alt+U / ⌥⌘U first, or select the tabs again.

Zen Browser Shortcuts — Frequently Asked Questions

How do I customize or remap Zen Browser keyboard shortcuts?

Open Settings > Keyboard Shortcuts, or visit about:preferences#zen-shortcuts. Click the field beside an action, press the new combination, then press Esc to save. A green outline means it saved; red means a conflict — press Backspace to clear it. Workspace 1–10 and Reset pinned tab to pinned URL have no defaults, so you assign those yourself. Firefox-only shortcuts that do not appear on this settings page cannot be remapped yet.

Why don't Ctrl+Alt shortcuts work in Zen Browser on Windows?

Zen's most important defaults use Ctrl+Alt (Compact Mode, Workspaces, Split View, floating sidebar). On Windows layouts with an AltGr key — German, Polish, UK, US-International, and many others — Ctrl+Alt is treated as AltGr and types a character instead of running the shortcut. Remap those actions to combos that do not use Ctrl+Alt, for example Ctrl+Shift, in Settings > Keyboard Shortcuts. This is tracked as zen-browser/desktop issue 9127.

What is the Zen Browser Compact Mode shortcut?

Ctrl+Alt+C on Windows and Linux, Option+Command+C on macOS. Ctrl+Alt+T / Option+Command+T toggles the floating toolbar, and Ctrl+Alt+S / Option+Command+S toggles the floating sidebar. In Compact Mode, enable Briefly make the toolbar popup when switching or opening new tabs under Settings > Look and Feel > Theme Settings so Ctrl+Tab still peeks at the tab strip.

How do I switch Workspaces in Zen Browser?

Backward workspace is Ctrl+Alt+Q (Option+Command+Q on Mac). Forward workspace is Ctrl+Alt+E (Option+Command+E on Mac). Switch to Workspace 1–10 is not bound by default — assign those ten shortcuts in Settings > Keyboard Shortcuts if you use numbered Spaces. Do not confuse these with Alt+1–8 / Command+1–8, which select tabs (including Essentials and pinned tabs), not Workspaces.

How do I split the view in Zen Browser?

Select multiple tabs in the sidebar first, then Ctrl+Alt+H (horizontal), Ctrl+Alt+V (vertical), or Ctrl+Alt+G (grid) on Windows and Linux. On Mac those are Option+Command+H, V, and G. Ctrl+Alt+U / Option+Command+U unsplits all. Zen documents that Toggle Split View currently applies when selecting multiple sidebar tabs and does not work from inside an existing split.

Are Zen Browser shortcuts the same on Windows, Linux, and macOS?

Windows and Linux share the official table (Ctrl and Ctrl+Alt). On macOS, most Ctrl bindings become Command and most Ctrl+Alt Zen features become Option+Command. Exceptions matter: next/previous tab stays Ctrl+Tab because Command+Tab switches apps; Command+H hides the app so history uses Shift+Command+H; tab 1–8 uses Command+1–8, not Option+1–8; fullscreen is Control+Command+F, not F11.

How do I copy the current URL as Markdown in Zen Browser?

Ctrl+Alt+Shift+C on Windows and Linux, Option+Shift+Command+C on macOS, copies the current page as a Markdown link. Shift+Ctrl+C / Shift+Command+C copies the plain URL. Both are listed under Zen Features in Settings > Keyboard Shortcuts.

Does Zen Browser use Firefox keyboard shortcuts?

Yes. Zen is a Firefox fork, so new tab, find, bookmarks, DevTools, and most navigation keys match Firefox. Zen adds its own chords for Compact Mode, Workspaces, Split View, copy URL as Markdown, and the AI chatbot sidebar. Firefox shortcuts that do not appear in Zen's Keyboard Shortcuts settings cannot be remapped yet — report those on the Zen GitHub issues page. Mozilla's Firefox shortcut list is the reference for anything not in the Zen table.

What is Zen Glance and is there a keyboard shortcut?

Glance is Zen's in-place page preview. There is no dedicated default key in the official shortcut table. Open a preview with Alt+click (Option+click on Mac) on a link. With Glance open, Command+Enter (or the equivalent confirm key) expands the preview into a tab, and Escape dismisses it. Glance can also be toggled for context-menu search via zen.glance.enable-contextmenu-search in about:config.

How do Alt+1 through Alt+8 work with Essentials and pinned tabs?

On Windows and Linux, Alt+1 through Alt+8 select tabs by index and that index includes Essentials first, then pinned tabs, then regular tabs. Alt+9 jumps to the last tab, not tab 9. Example: three Essentials and four pinned tabs means Alt+8 is the first regular tab. On macOS use Command+1–8 and Command+9. Ctrl+Tab cycles tabs (Essentials, then pinned, then regular) and can be set to recently used order under Settings > General > Tabs.
