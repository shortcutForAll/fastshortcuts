Grok Build Keyboard Shortcuts

Searchable Grok Build shortcuts for the xAI agent TUI — open the live help with Ctrl+. (or Ctrl+X), cycle modes with Shift+Tab, navigate scrollback in vim mode, and interject while a turn runs. Pair with Claude Code shortcuts, Codex shortcuts, Muse Code shortcuts, and Cursor shortcuts for AI coding workflows.

Verified against xAI Grok Build docs · Last checked 2 October 2026

What this Grok Build cheat sheet covers

Grok Build is xAI’s terminal coding agent. Bindings are built into the TUI and are not user-remapped in most builds — the authoritative list is always the in-app panel (Ctrl+. or Ctrl+X). This page groups shortcuts the way developers search: prompt control, mid-turn interject, agent screen panes, scrollback (arrow vs vim mode), slash prefixes, and the VS Code / Cursor / Windsurf / Zed terminal exceptions that trip people up daily.

Use the Windows / Linux and macOS tabs below. Grok Build is a TUI, so most chords stay on Ctrl on both platforms — macOS mainly changes Alt → Option and Apple Terminal quirks. If you run Grok Build inside Cursor or VS Code, check the Integrated terminal overrides group in each tab before memorizing Ctrl+L. On Ghostty or WezTerm, enable Kitty keyboard protocol if Ctrl+Enter or Shift+Enter misbehave.

Learn these five first

Ctrl+P or ? (command palette) · Ctrl+. / Ctrl+X (shortcut list) · Shift+Tab (cycle Normal / Plan / Auto / Always-approve) · Ctrl+C (cancel turn) · @ and / (file search and slash commands).

Grok Build Shortcuts — Frequently Asked Questions

How do I see all Grok Build keyboard shortcuts?

Press Ctrl+. inside the TUI. If nothing happens, use Ctrl+X — xAI documents that fallback for Windows and terminals without the Kitty keyboard protocol. The panel lists every binding for your current focus (prompt vs scrollback vs dashboard).

Why does Ctrl+L open something different in Cursor?

VS Code-family integrated terminals reserve Ctrl+L for mid-turn interject. Extensions move to /plugins. See the Integrated terminal overrides group in the Windows / Linux or macOS tab above, and our Cursor shortcuts page for editor chords that sit beside Grok Build.

How do I enable vim mode in Grok Build?

Run /vim-mode or set [ui].vim_mode = true in ~/.grok/config.toml. Single-letter scrollback keys (j/k, h/l, g/G) only apply in vim mode; arrows and Ctrl chords work either way.

What does Shift+Tab do in Grok Build?

It cycles permission / planning modes — typically Normal, Plan, Auto (when enabled), and Always-approve. Ctrl+O toggles always-approve directly. Exact modes depend on your build and settings.

How is Grok Build different from Claude Code or Codex?

All three are terminal agents with slash commands, but the maps differ. Grok Build emphasizes in-TUI help (Ctrl+.), vim scrollback, rewind via double-Esc, and terminal-specific interject keys. Use our Claude Code and Codex cheat sheets for those tools.

Where does xAI document Grok Build shortcuts?

Official reference: docs.x.ai/build/keyboard-shortcuts. The changelog at x.ai/build/changelog notes when bindings change (voice, dashboard, multiline, WezTerm).
