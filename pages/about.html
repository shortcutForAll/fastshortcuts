About

FastShortcuts

An independent keyboard shortcut reference. Each cheat sheet is compiled from official vendor documentation, searchable, and split by Windows, macOS, and Linux when the defaults differ. Guides stay free. Paid placements are labeled.

Who runs this

FastShortcuts is an independent project published at fastshortcuts.com. There is no fictional editorial team and no personal name on this page. The public mailbox and source repo are how to reach the person who publishes it.

How shortcuts are verified

Every cheat sheet is compiled from that tool’s official keyboard-shortcut documentation (linked in the page footer). Platform tabs show Windows/Linux and macOS separately when the vendor ships different defaults. When a vendor changes a default — Cursor, Warp, Claude Code, and similar tools do this often — the page is updated and the visible “last verified” date is refreshed where it exists.

If a shortcut on the site does not match what you see in the app, email owner@fastshortcuts.com with the tool, the OS, and the official doc URL if you have it.

What each sheet includes

  • Live search on the page
  • Windows, macOS, and Linux keys when the vendor’s defaults differ
  • A PDF download for offline use
  • A link to the official shortcut docs in the footer
  • No popup, signup wall, or email gate
  • Paid placements marked as sponsored

Learn the 15–20 shortcuts you actually use in your main tool first. That is enough to stay on the keyboard most of the day.
